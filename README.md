# تطبيق المفقسة - مشروع جاهز لتحويل APK

## الطريقة 1: بدون أي برامج (GitHub، من الموبايل أو الكمبيوتر)
1. أنشئ مستودع جديد على github.com وارفع محتوى هذا المجلد كاملاً (ملفات ومجلدات، بما فيها .github).
2. افتح تبويب Actions ثم Build APK ثم انتظر 5 إلى 8 دقائق.
3. افتح التشغيل المنتهي ونزّل الملف incubator-apk من قسم Artifacts، فيه app-debug.apk.

## الطريقة 2: على الكمبيوتر
المتطلبات: Node 20 أو أحدث، Java 21، وAndroid SDK (يأتي مع Android Studio).
```
npm install
npm run apk
```
الناتج: android/app/build/outputs/apk/debug/app-debug.apk

## ملاحظات
- شغّل التطبيق مرة واحدة واسمح بالإشعارات، وفي إعدادات أندرويد اسمح بـ "المنبهات والتذكيرات" وأوقف توفير البطارية للتطبيق.
- لتعديل التطبيق: عدّل www/index.html ثم أعد البناء.
- نغمة الإشعار: المشروع يحوي نغمة رنين في resources/ringtone.wav. لاستبدالها بنغمتك ضع ملفك (wav أو mp3 أو ogg) في نفس المجلد باسم ringtone وأعد البناء.
- أيقونة التطبيق: مجلد resources/icons يحوي أيقونات أندرويد الجاهزة، ويُنسخ تلقائياً أثناء البناء.
- النسخة الاحتياطية: من زر «نسخة احتياطية» في أعلى التطبيق تنسخ بياناتك كنص وتلصقها لاحقاً للاسترجاع.
